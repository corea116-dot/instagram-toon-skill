# 툰 작업실

이 Mac의 Codex로 인스타툰을 만들고, 웹 화면에서 진행 상황·대본·그림·게시 상태를 확인하는 개인용 대시보드입니다. 기존 `episodes/` 결과물을 읽고, 새 작업만 별도 에피소드 폴더에 만듭니다.

## 열기

Finder에서 **`툰 작업실 열기.command`**를 두 번 누르거나, 터미널에서 실행하세요.

```sh
cd dashboard
npm ci
npm run build
npm start
```

[이 Mac에서 작업실 열기](http://localhost:4318)

처음에는 **Mac에서 비밀번호를 직접 정합니다.** 사용자 비밀번호는 미리 설정하지 않았습니다. `연결과 알림 → Codex 연결하기`를 누르면 현재 Mac의 모델 목록을 읽어옵니다. 제작을 시작하는 요청과는 별도입니다.

필요한 프로그램은 Node 24 이상, 현재 로그인한 Codex CLI, `uv`, 기존 인스타툰 스킬과 그 제작 도구입니다. 의존성을 다시 설치할 때는 이 폴더에서 `npm ci`를 실행합니다.

## 사용하는 순서

1. **새 인스타툰 만들기**에서 주제를 직접 정하거나 자동 선택합니다.
   **전체 컷 수**와 **결과 이미지 수**를 각각 선택할 수 있습니다. 컷은 장면 수이고, 이미지는 게시할 파일 수입니다. 직접 선택은 3~40컷, 1~10장이며 한 이미지에 1~4컷을 담을 수 있는 조합만 허용합니다. 둘 다 자동이면 내용에 맞춰 이미지 5~9장과 필요한 컷 수를 정합니다. 예약 제작도 같은 선택을 사용합니다. 기존에 시작한 작업의 확정된 배치는 바꾸지 않습니다.
2. **중간에 내가 확인하기**는 처음에 켜져 있습니다. 대본과 완성된 그림에서 각각 멈춥니다. 끄면 사람의 확인만 생략하고 자동 검사는 유지합니다.
3. 대본의 글을 선택하거나 그림의 위치를 눌러 **수정 메모**를 남깁니다. **메모대로 수정 요청**을 누르면 해당 단계부터 다시 만들고 검사합니다.
4. 게시 방식은 **내가 게시 버튼 누르기** 또는 **정한 시간에 자동으로 게시하기**입니다. 게시 시간이 지났다면 완성과 필요한 확인이 끝나는 즉시 올립니다.
5. 실제 게시물 번호와 주소를 다시 확인한 뒤에만 **게시 완료**로 표시합니다. 응답이 끊겼을 때는 같은 게시 요청을 반복하지 않습니다.

**작업 흐름**에서는 상자와 연결선을 편집하고 단계를 추가합니다. 필수 검사 순서를 건너뛸 수는 없습니다. 작은 화면에서는 아래 단계 버튼을 눌러 편집할 도우미를 고를 수 있습니다. 도우미의 모델·생각하는 깊이·지시는 진행 중인 작업에도 반영합니다. 작업 중인 응답의 중단을 확인한 뒤 같은 단계와 대화에서 이어갑니다. 이미 끝난 단계는 다시 만들지 않습니다. 단계 추가와 순서 변경은 새 작업부터 적용합니다.

**예약**은 한국 시간 기준입니다. 여러 제작 예약을 놓쳤으면 가장 최근 것 하나만 시작합니다. 예약을 만든 시점보다 앞선 일을 소급해서 만들지는 않습니다. Mac이 잠들었거나 꺼져 있을 때는 제작할 수 없습니다. 켜진 뒤 작업실이 실행되면 밀린 예약을 확인합니다.

`연결과 알림 → Mac 로그인 때 작업실 열어두기`를 켜면 **다음 Mac 로그인부터** 작업실이 자동으로 실행됩니다. 현재 실행 중인 서비스는 이 버튼으로 중지하거나 다시 시작하지 않습니다. 자동 시작 등록은 아직 켜놓지 않았습니다.

## 외부 접속과 계정 연결

현재 기본 주소는 이 Mac 안에서만 열립니다. **주소를 입력하는 것만으로 외부 접속이 만들어지지는 않습니다.** 밖에서 아이폰으로 사용하려면 소유한 고정 HTTPS 주소를 이 Mac의 `127.0.0.1:4318`로 연결해야 합니다. 외부 연결은 사용하는 환경에서 별도로 설정하고 확인합니다.

연결 담당자가 확인할 사항:

- 인증 화면을 포함한 웹 요청과 `/api/events`의 실시간 연결을 전달합니다. 프록시의 응답 모아 보내기는 끕니다.
- 원래 공개 주소의 `Host`를 유지하고 `X-Forwarded-Proto: https`와 올바른 접속자 정보를 전달합니다. 앱은 로컬 프록시만 신뢰하고 허용된 주소만 받습니다.
- 인스타그램이 이미지를 가져갈 수 있도록 서명과 유효시간이 붙은 `/media/...` 주소는 외부에서 접근할 수 있어야 합니다. 그 외 결과물과 설정은 작업실 로그인 뒤에만 볼 수 있습니다.
- 새 주소를 `연결과 알림 → 외부 접속 주소`에 저장하고, 아이폰의 모바일 데이터로 직접 접속해 확인합니다.

인스타그램 공식 연결에는 새 크리에이터/비즈니스 계정 외에 **Meta 연결 앱**이 필요합니다. 앱의 Instagram Login 설정에서 `instagram_business_basic`, `instagram_business_content_publish` 권한을 준비하고, 로그인 후 돌아올 주소를 `https://내-주소/api/instagram/callback`으로 등록합니다. 연결용 앱 번호와 비밀키를 대시보드의 **처음 연결에 필요한 정보**에 입력한 다음 **인스타그램 계정 연결**을 누릅니다. Meta의 권한 심사나 시험 사용자 조건은 앱 상태에 따라 다르므로 실제 연결 때 확인해야 합니다.

연결용 비밀키와 계정 토큰은 이 앱이 만든 `.data/` 저장소에서 암호화합니다. `.data/local.key`와 데이터베이스를 함께 보관해야 복구할 수 있습니다. 다른 앱의 로그인 파일이나 키체인에서 가져오지 않습니다. 계정 연결이 만료되면 화면에서 다시 연결합니다. 자동 토큰 갱신은 현재 제공하지 않습니다.

아이폰 알림은 HTTPS 연결 후 Safari의 **공유 → 홈 화면에 추가**로 설치한 작업실에서 **이 기기에서 알림 켜기**를 누릅니다. 시험 알림은 전송 결과와 실제 수신을 따로 확인합니다. 실제 아이폰에서의 알림 수신은 아직 검증하지 않았습니다.

## 검증과 현재 제한

대시보드가 시작한 Codex 프로세스에는 `approvals_reviewer="auto_review"`를 적용합니다. 일반 명령의 추가 권한은 Codex 자동 검토로 처리하며, 전역 설정은 바꾸지 않습니다. 실행 환경의 제한, 대본·그림 중간 확인, 게시 조건은 유지됩니다. 자동 검토에서 거절되거나 앱 접근에 사람의 확인이 필요한 경우에는 멈출 수 있습니다.

```sh
npm test
npm run test:ui
npm run check:codex
```

- `npm test`: 예약, 승인, 수정 메모, 두 번 재시도, 실행 중 설정 변경, 게시 중복 방지, 결과 변경 감지, 로그인 보호 등을 임시 폴더와 모의 응답으로 확인합니다.
- `npm run test:ui`: 이전 Chrome 기반 개발 검사입니다. Aside를 사용하는 환경에서는 이 명령 대신 Aside에서 화면과 API를 확인합니다. 임시 데이터베이스를 사용하고 기존 결과물은 읽기만 합니다. **제작과 게시를 실행하지 않습니다.** Mac 자동 시작도 변경하지 않습니다.
- `npm run check:codex`: 실제 Codex 연결, 모델 목록, 기존 스킬 노출을 확인합니다. 새 제작 요청은 보내지 않습니다.
- 로컬 검증 증거와 개인 실행 데이터는 이 저장소에 포함하지 않습니다.

계정·고정 HTTPS 주소가 아직 없으므로 **실제 인스타그램 로그인·게시, 외부 아이폰 접속·알림은 미검증**입니다. 새 에피소드를 Codex로 처음부터 끝까지 만드는 실제 제작도 아직 실행하지 않았습니다. CLI 실행 환경에서 기존 브라우저·그림 도구를 사용할 수 없으면 이유를 표시하고 멈추도록 구현했습니다. 도구 연결만으로 제작 완주를 보장하지 않습니다.

현재 게시 연결은 이미지 1~10장과 게시글 2,200자까지 다룹니다. 네이버 블로그·Threads·YouTube Shorts와 영상의 외부 게시 연결은 포함하지 않습니다. 필요한 단계는 워크플로우에 추가할 수 있지만 새로운 SNS 게시 연결은 별도로 구현해야 합니다.

## 개발·보관 위치

### 이 Mac의 휴대폰 접속

Tailscale을 별도로 설정했다면 등록된 아이폰에서 연결을 켠 뒤 `http://<내-Mac의-Tailscale-이름>:4319`를 엽니다. 이 주소는 개인 Tailscale 네트워크 안에서만 열리며 인터넷에 공개되지 않습니다. Mac과 작업실 서버가 켜져 있어야 합니다. 로그인 비밀번호는 작업실의 초기 설정에서 직접 지정합니다.

`settings.privateUrl`은 개인 접속의 주소·요청 출처 확인에만 사용합니다. 인스타그램이 이미지를 가져가는 공개 주소(`publicUrl`)와 분리했습니다. 현재 HTTP 개인 연결에서는 홈 화면 알림과 HTTPS가 필요한 브라우저 기능을 사용할 수 없습니다. HTTPS Serve 활성화 후 해당 주소로 전환할 수 있습니다.

연결 재실행: `tailscale serve --bg --http=4319 http://127.0.0.1:4318`. 이 연결만 해제: `tailscale serve --http=4319 off`.

- 화면: `src/`, 공통 설정: `shared/`
- 실제 실행·저장·계정 연결: `server/`
- 로컬 상태·비밀번호·연결 정보: `.data/` — Git 제외
- 에피소드 결과: 상위 폴더 `episodes/`
- Mac 자동 시작을 켰을 때만: `~/Library/LaunchAgents/local.instagram-toon.dashboard.plist`

개발 화면은 `npm run dev`로 엽니다. 기본 포트는 4318이며 `TOON_PORT`, `TOON_DATA`, `TOON_PROJECT`로 바꿀 수 있습니다. 같은 저장소를 두 서버에서 동시에 사용하지 마세요. 운영 자동화나 다른 Codex 서비스는 이 앱이 중지하지 않습니다.

## 완성 인스타툰을 모션그래픽으로 만들기

- 작업실의 **모션그래픽 만들기** 버튼에서 원본 에피소드를 선택합니다.
- 완료된 작업 카드·최근 결과물·결과 모아보기·원본 보기 화면에서도 해당 에피소드를 선택한 상태로 바로 시작할 수 있습니다.
- 대본·최종 이미지·검수가 끝난 결과만 선택합니다. 원본 작업이 진행 중이면 완료 후 이용합니다. 같은 에피소드의 영상 작업이 이미 있으면 기존 작업으로 연결합니다.
- 장면·연출 기획은 Astra low, 제작은 GPT-6.1 Sol high의 별도 Codex 작업자로 실행합니다. 독립 대본·화면 검수와 파일 검사도 거칩니다. 기준 대화는 2026-10-04 15:50 KST 이후 승인한 상황극 각색 방향입니다.
- 영상 작업은 원본을 보존하고 `episodes/<원본>/motion/desk-<작업 ID>/`에 저장합니다. 완성되면 작업 상세에서 재생·다운로드합니다. 기존 대시보드에 접속할 수 있는 휴대폰에서도 같은 화면을 이용합니다. 별도 외부 업로드나 인스타그램 게시는 하지 않습니다.
- 실행 중 중지·실패 후 이어서 시작을 지원합니다. 영상의 원본 인스타툰 수정이나 자동 게시 설정은 제공하지 않습니다. 원본이 변경된 경우 기존 검수는 재사용하지 않습니다.

모션 경로 테스트는 임시 원본과 모의 Codex 작업자, 짧은 테스트용 MP4를 사용합니다. 실제 이미지 생성·Qwen 음성·30초 영상 제작 완주는 별도 실행 결과로 확인해야 합니다.
