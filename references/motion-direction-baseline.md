# 모션그래픽 대본·연출 기준

새 모션그래픽 기획자는 아래 원칙을 원본 주제에 맞게 적용한다. 마지막 영상의 겉모양이나 재생 속도만 복제하지 않는다.

1. 인물에게 당장 필요한 질문 하나에 집중한다. 질문과 관계없는 원본 정보는 덜되, 남긴 주장에 필요한 조건은 함께 전달한다.
2. 정책 이름이나 예상 가능한 퀴즈보다 손해·착각·갈등이 보이는 행동으로 시작한다. 첫 질문의 답을 숨기지 말고, 답에서 다음 궁금증으로 이어간다.
3. 행동에 이유와 결과를 붙인다. 물건을 들고 설명하기보다 지갑을 닫다 제지당하기, 비용을 확인하려 폰을 내밀기처럼 상대와 상황이 바뀌게 한다.
4. 손·물건 가까이 → 얼굴 반응 → 두 사람 → 필요한 화면 → 마지막 표정처럼 이야기의 초점에 따라 화면 크기를 바꾼다. 불필요한 배경 그림은 제거한다.
5. 자막은 대사, 큰 화면 글자는 핵심 단어나 확인 위치에 쓴다. 그림으로 보이는 행동을 설명 카드로 반복하지 않는다.
6. 반응·전환은 빠르게, 확인 화면은 읽을 만큼 유지한다. ‘2초마다 전환’이나 전체 속도 증가가 아니라 새 행동·의문·발견을 기준으로 편집한다.
7. 음악·효과음을 계속 채우지 않는다. 후킹 행동 때 음악을 잠깐 끊고, 발견 때 선택적으로 효과음을 쓰며, 마지막 농담 직전에는 작은 정적을 둔다. 결말 자막은 해당 순간에 보여준다.
8. 마무리는 도입 행동을 회수하는 인물 반응과 필요한 정보의 짧은 재확인으로 만든다. EP-021의 지갑 농담을 다른 에피소드에 반복하지 않는다.

EP-021 가안 예시: 0–3초 지갑을 닫다 제지 → 3–7초 무료라는 착각 해소 → 7–11초 나는 얼마? → 11–18초 확인 위치 → 18–24초 조건 주의 → 24–30초 지갑을 다시 여는 웃음. 실제 완성본의 세부 타이밍이 우선이며, 이 구간은 다른 주제에 강제하는 템플릿이 아니다.

정보 화면은 실제 확인한 화면 또는 ‘설명용 화면’으로 명시한 예시를 쓴다. 가짜 개인 부담액이나 실제 조회했다는 주장을 만들지 않는다. 동작 이미지는 원본 에피소드 그림을 참조해 새로 만든다.

기획자는 brief에 각 원칙을 실제 장면으로 연결해 짧게 기록한다. 내용 검수의 첫 맹독 단계에는 이 의도 설명을 먼저 넘기지 않는다. 한 질문, 행동의 결과, 초반 약속에 대한 답, 문자·음성 중복, 읽을 시간, 도입을 회수하는 결말을 검수한다.

시청 유지율 개선은 아직 가설이다. 같은 주제에서 도입을 달리 비교하고 초반과 설명 구간의 이탈을 구분해야 연출 문제와 주제 적합성을 판단할 수 있다. 한 편의 조회수나 기술 검수로 성과 개선을 보장하지 않는다.
