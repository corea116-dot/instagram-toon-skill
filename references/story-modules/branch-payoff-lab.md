# Branch Payoff Lab

StoryCritic 실패가 `mechanism`, `beats`, `payoff`, `duplicate`일 때만 한 번 실행한다. 완성 스크립트를 무작정 다시 쓰지 않고 최대 세 개의 짧은 인과 경로를 비교한다.

## 입력

- 선택된 direction 또는 현재 스크립트
- StoryCritic의 정확한 `failure_class`와 수정 지시
- 보존해야 할 주제, 인간적 사실, 캐릭터, 안전 제한

## 후보 형식

각 후보는 다음 항목을 갖는다.

- `branch_id`
- 주 유머 엔진과 실패 원인을 고치는 한 문장 설명
- 서로 다른 네 개의 보이는 상태 변화
- 각 변화의 원인과 다음 변화로 이어지는 결과
- 짧은 payoff와 오프닝을 다시 읽게 하는 근거
- 중복·민감성·시각화 위험

## 선택 규칙

1. 후보는 최대 세 개만 만든다.
2. 실패 원인을 직접 고치지 못하는 후보는 버린다.
3. 네 변화가 모두 같은 행동의 반복이면 버린다.
4. 오프닝 질문과 payoff가 서로 답하지 않으면 버린다.
5. 가장 적은 설정 변경으로 원인과 반전을 함께 고치는 후보 하나만 선택한다.
6. 선택한 한 방향만 WriterAgent에 넘기고 StoryCritic을 다시 실행한다.

실행은 최대 1회이며, 기존 스크립트 재작성 총 2회 상한 안에 포함된다. StoryCritic이 최종 승인권을 유지한다.
